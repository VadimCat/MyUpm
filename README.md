# Rive Unity UPM

Rive Unity v0.5.2 with a redraw fix for animated state machines: `ArtboardLoadHelper.Tick`
returns whether the state machine advanced and `RiveWidget` redraws when it did. The native
libraries and Unity metadata match the upstream release.

Upstream: https://github.com/rive-app/rive-unity/tree/v0.5.2
